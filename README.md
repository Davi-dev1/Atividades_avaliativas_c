# Atividades de Código C Solicitadas pelo Professor em Sala de Aula
<P>Esse repositório possui códigos solicitados em aula por meu professor, para exercitar conceitos e conteúdos aprendidos em sala de aula por meio do código C.</P>

## Conteúdos:
<ul>
<li>Comandos de entrada e de saída: Cadastro simples</li>
<li>Trocas de valores e ordenação de dados de variáveis</li>
<li>Operadores Aritméticos, Comparações e Operadores Lógicos</li>
<li>Condicionais(If/Else)</li>
<li>Estruturas de seleção(Switch/Case)</li>
<li>Estruturas de Repetição(While,For e do While)</li>
</ul>

## Importância
<p>Conceitos aprendidos na aula foram muito importantes e consolidados aqui nesses exercícios do qual pratiquei para aumentar e treinar mais ainda meu repertório de conceitos de Programação.</p>
